# 🌊 Ocean Dream – Underwater Ocean Tunnel

An immersive underwater animation project created using HTML, CSS, and JavaScript. It features a beautiful ocean tunnel environment with animated marine life, glowing coral reefs, tropical fish, floating bubbles, and dynamic underwater lighting.

## ✨ Features
- Cinematic underwater ocean environment
- Animated whale, dolphins, manta ray, and sea turtle
- Randomly generated tropical fish and bubbles
- Glowing coral reefs and swaying seaweed
- Animated sunlight and underwater light rays
- Interactive mouse-based parallax effect
- Responsive full-screen visual experience

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

## 🎯 Project Objective
To create an immersive underwater visual experience using CSS animations, JavaScript DOM manipulation, and interactive visual effects without requiring external animation libraries.
